# Pacote de redesign D&A Print — Claude Code

Este ZIP contém **10 referências visuais**, imagens e ícones originais do projeto, tokens CSS de referência, um guia de funcionalidades e um prompt pronto.

## Aplicação
1. Faça backup/commit LOCAL do estado atual, sem enviar ao remoto automaticamente.
2. Extraia este pacote em uma subpasta dentro do projeto PCP (ex.: `referencias-redesign/`) ou mostre ao Claude o caminho da extração.
3. Abra `04_prompt/PROMPT_PARA_CLAUDE_CODE.txt` e envie seu conteúdo ao Claude Code, ajustando o caminho da subpasta se necessário.
4. Solicite somente a auditoria primeiro. Aprove o plano antes de permitir mudanças.
5. Após testar localmente, decida por conta própria quando publicar.

**Observação:** o ZIP NÃO contém uma versão nova funcional do sistema. É um kit de referências para o Claude adaptar a aplicação existente. Os mockups podem conter textos, valores e controles ilustrativos ou não implementados; preserve sempre os dados e funcionalidades reais.
